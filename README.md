# Mouton Noir — site statique

Structure prête pour Cloudflare Pages.

- `index.html` : accueil FR
- `en/` : version anglaise
- `images/` : remplacer `tattoo1.jpg` à `tattoo10.jpg` et `logo.jpg` par les fichiers définitifs en conservant les noms.
- `styles.css` : design global
- `main.js` : routage minimal du bouton de langue, sans tracking ni cookies.
- `projet.html` / `en/projet.html` : formulaire ouvrant le logiciel de messagerie via `mailto:`.

## Avant mise en ligne
1. Acheter/configurer le domaine choisi.
2. Remplacer les placeholders images.
3. Générer `sitemap.xml` avec le domaine réel.
4. Vérifier le formulaire sur appareil disposant d'un logiciel mail.
5. Déployer sur Cloudflare Pages et tester le domaine de prévisualisation.
